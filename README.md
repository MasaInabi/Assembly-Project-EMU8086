# Assembly Project - EMU8086

## Description
This project is an Assembly language program implemented using EMU8086.  
It demonstrates basic low-level programming concepts and includes screenshots of the results.

## Features
- Assembly language implementation
- EMU8086 simulation
- Result screenshots included in the report

## Technologies Used
- Assembly
- EMU8086

## Project Files
- `assignment.asm`: Assembly source code
- `resultsScreanShots-masaInabe_noorasfour.pdf`: project results and screenshots

## How to Run
1. Open `assignment.asm` in EMU8086.
2. Compile the code.
3. Run the program.
4. Check the PDF file for result screenshots.
